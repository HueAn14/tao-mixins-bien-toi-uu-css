[Thực hành] Tạo Mixins & Biến Tối Ưu CSS

Sử dụng SASS Variables & Mixins để loại bỏ trùng lặp code và dễ dàng quản lý giao diện

🎯 Mục Tiêu & Kết Quả Đạt Được

  • ✔ Tạo Mixins giúp giảm lặp code: Đóng gói các thuộc tính định kiểu nút (button-style) và thẻ hộp (box-style).
  • ✔ Dùng Biến kiểm soát toàn bộ giao diện: Quản lý màu sắc ($primary-color, $text-color), cỡ chữ ($font-large, $font-medium), padding và box-shadow.
  • ✔ Cải thiện tính tái sử dụng: Khi cần thay đổi kiểu dáng hay màu sắc, chỉ cần cập nhật tại một file biến duy nhất.

4. Bảng So Sánh Trước & Sau Tối Ưu

Tiêu chí CSS Truyền thống (Trước tối ưu) SASS Variables & Mixins (Sau tối ưu)
Màu sắc & Kích thước Ghi cứng (Hardcoded: red, #222, 32px) khắp nơi. Tập trung trong _variables.scss ($primary-color, $font-large).
Lặp code kiểu dáng nút Mỗi loại nút phải viết lại padding, border-radius, color. Dùng @mixin button-style($bg) tái sử dụng 100%.
Kiểu dáng Card / Hộp Viết lại bóng mờ, bo góc, đệm lề cho từng thành phần. Dùng @mixin box-style chỉ bằng 1 dòng @include.
Bảo trì & Thay đổi giao diện Phải tìm và sửa thủ công ở hàng chục selector. Chỉ cần sửa biến một lần, toàn hệ thống tự động cập nhật.
